# German Federal States — Demographic Analysis

Python data analysis project examining population distribution,
gender ratios, and density across all 16 German federal states
using official Destatis government data (2023).

## Tools Used
Python · pandas · matplotlib · Jupyter Notebook

## Data Source
Destatis — Statistisches Bundesamt (Federal Statistical Office)  
Gemeindeverzeichnis, Gebietsstand 31.12.2023

## What This Project Analyses
- Population distribution across all 16 Bundesländer
- Male vs female breakdown by state
- Population density comparison
- East vs West demographic patterns

## Key Findings
- NRW, Bayern and Baden-Württemberg hold 50%+ of Germany's population
- Women outnumber men in every single state — relevant for 
  pension duration planning since women statistically live longer
- Eastern states show consistently lower density, a legacy of 
  post-1990 migration patterns
- Berlin and Hamburg reach 4000+ people/km² vs ~70 in rural east

## Relevance to Public Sector IT
Built to demonstrate applied data analysis using real German 
government data — directly relevant to data-driven planning 
in institutions like Deutsche Rentenversicherung Bund.
